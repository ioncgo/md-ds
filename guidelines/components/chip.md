# Chip

A chip is a small label with an icon and text. Once selected, it shows an x to remove it. In the dashboard, chips show the filters applied to a table.

Figma: https://www.figma.com/design/5nGbl24ZhF2RKmXg5dgtaN/Components?node-id=225-12800

## Usage

- **Applied filters:** each active filter shows as a selected chip above the table. The x removes that filter.
- **Unselected chip:** white with a border. Selecting it applies the filter and turns it grey.
- **Selected chip:** grey fill with an x.
- **Content:** an optional icon, then short text. Keep the text short, and give the full text in a tooltip if it gets cut off.
- **Not for statuses:** chips are interactive. A status that only shows information is a badge.
- **States:** default, hover, and focused. Focused shows the blue focus ring.
