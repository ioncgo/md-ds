# Search

The search input is a text field with a search icon on the left. Once the user types, a clear (x) button shows on the right. It helps people find an option fast in a long list.

## Usage

- **Where:** inside overflow menus, and inside filter menus.
- **When:** the menu has more than 5 options. With 5 or fewer, leave it out.
- **Why:** better discoverability. In a long list, the user types instead of scanning.
- **Clear button:** shows only when the input has text. It empties the input and brings back the full list.
- **Placeholder:** short, like "Search".
- **Sizes:** `sm` (28px), `md` (32px), and `lg` (40px).
- **States:** default, hover, focused, and active. Active means the input has text.

More menu rules: [Filtering menus](../compositions/table.md#filtering-menus).
