# Button split

The button split is one button with two parts. The label runs the main action, and the chevron next to it opens a menu of related actions.

Figma: https://www.figma.com/design/5nGbl24ZhF2RKmXg5dgtaN/Components?node-id=103-10891

## Usage

- **Main part:** runs the most common action in one click.
- **Chevron part:** opens a menu with the other options. Each item has an icon and a label.
- **When to use:** one action is the usual choice and a few close alternatives exist, like Save, with Save as draft as another option.
- **When not to:** don't put unrelated actions in the menu. If the actions are equal in weight, use a button group instead.
- **Menu size:** keep it short, 2 to 5 items. A divider can separate groups of actions.
- **Variants:** orange and white. The orange one follows the same rule as the primary button: one per view.
- **Sizes:** `sm` and `md`.
- **States:** default, hover, and pressed. Pressed means the menu is open, and the chevron flips up.
